# Feature Decision Rules

## Include in MVP

A feature belongs in the initial wallet MVP when it directly
supports:

- Wallet creation
- Wallet import/recovery
- Balance viewing
- Receiving
- Sending
- Transaction history
- Network switching
- Self-custody security

## Defer

Features should be deferred when they primarily introduce:

- Exchange functionality
- Fiat infrastructure
- Leverage
- Institutional custody
- Broad blockchain expansion
- Regulatory complexity unrelated to the wallet MVP

## Decision Principle

Prefer a smaller secure product over a larger product with
unclear security boundaries.
